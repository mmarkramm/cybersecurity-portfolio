## Linux Concepts Learned

### Home Directory (`~`)

`~` refers to the current user's home directory.

Example:

```bash
cd ~
```

### Current Directory (`.`)

`.` refers to the current working directory.

Example:

```bash
./program
```

### Parent Directory (`..`)

`..` refers to the directory one level above the current directory.

Example:

```bash
cd ..
```

## Offensive Security Notes

### Directory Enumeration

Websites may contain hidden directories that are not visible through normal navigation.

Enumeration tools can be used to discover hidden paths and content.

Examples:

* website.com/admin
* website.com/private
* website.com/backup

Discovering hidden directories can reveal functionality that is not directly linked from the main website.
